# Chris Herzig - Portfolio Website

Welcome to my personal portfolio website! This site showcases my skills, projects, and professional experience as a **Software Engineer** specializing in **C#**, **.NET**, **AI Engineering**, and **Web Development**. It serves as a comprehensive overview of my technical expertise, work history, and future aspirations.

---

## 🌟 **Features**

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Dark Mode**: Includes a toggle for light and dark themes, with dark mode as the default.
- **Interactive Portfolio**: Highlights my key projects with detailed descriptions and links to live demos or repositories.
- **Resume Section**: A detailed online resume with work experience, education, skills, and future projects.
- **Contact Form**: A functional contact form powered by **EmailJS** for direct communication.
- **Animations**: Smooth animations using **AOS (Animate on Scroll)** for a modern and engaging user experience.

---

## 🛠️ **Technologies Used**

### **Frontend**
- **HTML5**, **CSS3**, **JavaScript**
- **Bootstrap** for responsive design
- **Swiper.js** for interactive sliders
- **AOS.js** for scroll animations

### **Backend**
- **EmailJS** for handling contact form submissions

### **Design**
- Custom CSS for a unique and professional look
- Dark mode implementation with CSS variables and JavaScript
